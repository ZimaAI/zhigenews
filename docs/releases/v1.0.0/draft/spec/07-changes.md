## 同步与验证口径

r5同步两份设计、原型、需求/UX/领域/架构/验收、OpenAPI与样例、共享API说明和双向追踪。当前50 schemas、52操作、22份固定样例；24项需求与36项验收定义。保留stable ID并改写被用户替代的行为，新增匿名防滥用需求和后端验收。

检查应覆盖匿名自动进入/刷新、Cookie丢失、独立管理认证、403/429与配额、新闻弹窗与焦点、公开生成状态和旧内容保留、设置/引导、手机和键盘。实际结果只在阶段证据登记，本文件不宣告通过；原型Cookie或契约通过不代表生产网关、每日调度或Agent已实现。继续ITERATE调整方案。
