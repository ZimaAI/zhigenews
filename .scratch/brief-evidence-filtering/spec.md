# 简报逐条证据过滤

Agent 提交最终简报后，逐条校验证据。引用不存在、URL 无效、溯源信息不完整的新闻只剔除该条；继续过滤重复、发布时间无效或超出固定窗口的新闻。至少保留一条即按现有流程发布，不补足数量、不额外调用模型。

过滤后从保留内容重建标题和导语，所有输出保持一致。全部剔除时标记部分完成和空结果，不创建或发布空简报。正常空结果保持现有语义。

运行记录保存提交、保留、剔除数量及逐条原因；内部 limitations 驱动 partial 状态，读者正文不包含技术诊断。基础设施错误和取消继续传播，发布沿用既有幂等及重试流程。

验证混合有效/无效证据、畸形 URL、单条发布、全被剔除、输出一致性、诊断及重复执行不重复发布。
