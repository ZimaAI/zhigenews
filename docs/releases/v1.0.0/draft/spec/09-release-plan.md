# v1.0.0 交付与运行门槛

交付内容：后端源码与依赖锁、迁移、Linux容器/本地开发配置、两套独立Vue应用、共享API客户端/组件、环境模板、操作说明、阶段验收报告、后端交接包与最终证据。正式新闻、事件和发布结果只来自实际后端；测试夹具必须明确标记模拟。
