原型浏览器检查优先覆盖 AC-UI-003/005/008/011/012/013/015 的完整操作路径，以及 AC-UI-010 的布局与键盘；其余状态逐项记录。后端正式实施和验收时将 AC-BE/INT 拆成可运行检查并附环境、输入、预期、实际和证据路径，不能继承原型阶段的通过状态。

历史 r3 保留 AC ID 并改写已被用户替代的旧规则：AC-UI-003/004 对应三字段偏好，AC-UI-007/008 与 AC-INT-001/002 对应每日站内发布；旧邮件、暂停和扩展偏好要求不再属于当前验收。Agent 长期记忆仍由 AC-BE-010 验证。

本轮 r5 替代原用户登录/注册、阅读标记和整理记录规则：保留AC-UI-002/005/006/009与AC-BE-002/014的稳定ID并改为匿名身份、新闻弹窗及公开进度；新增REQ-ABUSE-001和AC-BE-016/017。原型的Cookie和配额演示只验证开发中间件，不等于生产FastAPI、持久会话或网关抗攻击验收。
