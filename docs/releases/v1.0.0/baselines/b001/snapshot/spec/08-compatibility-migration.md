# v1.0.0 安装、兼容与迁移

这是首个正式版本，没有既有生产数据库、公开客户端或已交付来源基线。原型 localStorage 和 dev-only `.demo` 数据均为模拟数据，不迁移至正式数据库；原型保持独立用于对照，不打包进正式应用。

数据库采用 MySQL 8.4/InnoDB/utf8mb4，通过 Alembic 显式迁移。首版迁移创建会话、偏好、配额、采集、运行/事件、配置、简报/发布、记忆、评估及 outbox 表；LangGraph 适配器自己的 setup 创建 checkpoint 表。新环境先迁移，再通过 CLI 创建管理员与非秘密默认配置。启动 API 不得静默删除或重置数据库。

API 前缀 `/api/v1`，唯一边界为 OpenAPI。服务器 UTC 存储时间，展示/每日计划使用 Asia/Shanghai；未知发布时间和用量保持 null。用户及管理员不同 Cookie，生产 Secure、HttpOnly、SameSite=Lax；本地 HTTP 开发允许关闭 Secure。

会话默认匿名30日、管理8小时，服务端执行过期/撤销；丢失匿名 Cookie 不可找回旧账号。事件默认保留90日、未被引用的来源快照默认保留30日；运行/简报/评估仍引用的快照不得清理。首版不自动删除用户简报和偏好。风险以近期限流次数分档（1次 watch、5次及以上 high），仅是管理提示，不声称识别自然人。默认不信任转发IP头，只有显式配置的代理网段可使用它。

升级操作先备份 MySQL 和 data 持久卷，记录当前应用修订及 Alembic 版本。本版无旧产品数据升级矩阵；仍验证空库安装、重复迁移幂等和进程重启持久数据读取。失败时停止新请求/worker，修复后前滚；初始迁移的 downgrade 会删除表，不能作为无损回滚。生产数据破坏、迁移和部署需要另外授权。

现有原型中旧 `/preferences`、`/delivery` 页面链接可重定向到设置；用户运行详情转今日。正式 HTTP 不提供已删除的用户密码、阅读标记或运行事件接口，匿名身份不得访问管理API。
