# 来源批量删除独立于页面执行并全局互斥

管理员离开或刷新页面后，来源批量删除继续执行，返回页面可恢复查看进度，因此将删除及其进度作为持久后台任务，而不依赖浏览器连接或原删除请求的存续。删除所选来源与删除全部失效来源共用这一机制，全系统同一时间只允许一个活动来源批量删除任务；牺牲多个管理员同时发起不同删除批次的能力，以便各页面共享明确的执行状态并避免重复清理。

每次任务固定创建时的候选来源集合，执行时逐项重新校验；全部失效来源删除会跳过已经恢复的来源，取不到采集锁的来源立即跳过，本轮不反复重试，执行期间新失效的来源留待下次操作。删除数据范围继续遵循 [删除采集历史决策](0001-delete-source-collection-history.md)。
