# 模型文件配置与 Agent 代码常量

管理员端删除模型与连接、Agent 配置页面及管理 API。模型端点、模型 ID、API key、上下文窗口与思考开关通过后端配置文件维护；Agent 预算、工具和系统提示词由代码常量维护。生成和评估直接使用当前部署配置，不再要求数据库模型验证或配置发布。

保留运行与评估的私有配置快照和历史查询，已有数据库配置不再影响新任务。评估仍保留固定输入、规则评分和可选模型评分。同步活动 API 契约、客户端和操作文档；历史基线与原型保持归档。

验收：被移除管理路由不可访问；文件设置用于新任务且密钥不出现在公开 DTO；代码常量无法被管理 API 修改；评估使用当前配置；前后端相关检查通过。
