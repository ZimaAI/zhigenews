# 双端原型范围（DISCOVER 草稿）

当前无原型代码；以下是进入 ITERATE 后的实施范围。视觉规范唯一来源为根目录 `design.md`，不另建一套后台配色。

## 用户端独立项目

| 页面 | 用户能做什么 | 必须演示的关键状态 |
| --- | --- | --- |
| `/login`、`/register` | 登录或创建账户 | 校验失败、身份失效、提交中 |
| `/onboarding` | 填关注方向、主题、关键词及可选推送 | 保留草稿、跳过外部渠道、保存失败 |
| `/today` | 读今日简报、按主题看内容、手动生成 | 未配置、暂无简报、生成中保留旧内容、无匹配、部分完成、失败 |
| `/briefs/:id` | 完整阅读、看推荐理由/来源/偏好快照 | 引用缺失提示、内容版本、生成与投递分开 |
| `/briefs` | 日期/主题/状态筛选历史 | 无历史、无筛选结果、分页、返回恢复筛选 |
| `/preferences` | 保存主题、包含/排除词、匹配模式、来源偏好和阅读参数；查看/清理长期记忆 | 校验、未保存离开、保存后下次生效；记忆来源、无记忆、清理失败保留数据 |
| `/delivery` | 设置站内/邮件、时间/时区、暂停、测试、重试 | 未验证邮箱、目的地脱敏、发送失败、未知状态、明确下一次日期 |
| `/runs/:id` | 查看本人简化时间线、取消 | 断线待确认、补齐事件、正在取消与已取消分开 |

默认首页是今日简报。新闻流宽不超过 900px，详情正文不超过 760px。1440px 默认完整侧栏+单列；移动底部只放当前实现的“今日、历史、设置”。

## 管理员端独立项目

| 页面 | 操作 | 必须演示的关键状态 |
| --- | --- | --- |
| `/login` | 管理员登录 | 普通用户禁止进入，服务端拒绝语义可见 |
| `/overview` | 看运行、采集、投递的实际异常 | 无运行样本不制造百分比、部分组件不可用 |
| `/sources`、`/sources/:id` | 管理 NewsNow/RSS、启停、轮询、验证、手动采集 | 不同源间隔、待验证/退避、最近成功与下次运行 |
| `/models` | 提供商、模型 ID、base URL、key 引用、角色、连接测试 | key 不回显、失败保留非秘密输入、无可用模型 |
| `/agent-configs` | 参数/提示词/工具/子 Agent 配置草稿与发布 | 校验、版本差异、新运行生效 |
| `/runs`、`/runs/:id` | 按状态/模型/时间过滤，查看父子运行及实际事件 | 工具重复调用、缺失结果修复、摘要压缩、预算耗尽、取消、异常 |
| `/evaluations`、`/evaluations/:id` | 管理固定样例，运行实验，比较配置与评分 | 排队/运行/失败、人工与模型评分来源、未配置评估模型 |
| `/users`、`/deliveries` | 用户状态和投递故障管理 | 权限拒绝、重试原简报、提交成功与送达未知分开 |

后台使用同样设计变量和基础组件，表格/时间线比普通用户端更详细；敏感信息脱敏，长日志只在局部滚动。

## 原型交互与数据约束

原型有固定时钟、集中 mock adapter、状态场景选择与重置入口；页顶标注“交互原型 · 示例数据”，不调用付费模型或发送邮件。

第一条可点击链路：首次配置 → 保存订阅 → 生成 → 查看简报 → 打开原文/来源 → 查看邮件失败 → 重试同一期。

管理链路：新增模型配置 → 模拟连接测试 → 发布 Agent 参数 → 进入示例运行 → 查看工具/摘要/子任务 → 比较两次固定样例实验。

场景样例必须标明 synthetic。每个可用按钮产生真实原型状态变化；尚未实现的入口不假装成功。根据 contract 定义校验 mock，不让两个前端各自发明协议。

原型检查目标：桌面与 320/375/768px 重排、200% 文字缩放、长标题/长关键词、表单保留输入、键盘导航和弹窗焦点。此处是目标，尚未完成验证。
