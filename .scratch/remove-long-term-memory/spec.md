# 移除长期记忆机制

按用户 2026-09-19 的决定，删除当前长期记忆机制，未来另行设计实现。

范围：移除偏好保存和简报发布时的记忆写入、任务启动时的记忆同步、用户记忆 Store、记忆查询/删除 API 与客户端类型，以及摘要中间件中的记忆注入和预算计算。同步活动契约、原型模拟接口和当前规格，保留冻结基线与交接快照作为历史记录。

保留用户显式偏好、偏好版本、简报与发布记录、线程消息、会话摘要及 MySQL checkpoint。此次不删除现有数据库数据，不引入替代记忆机制。

验收：运行路径不读写长期记忆；摘要仅渲染会话摘要；记忆 API 不再注册；偏好保存、简报发布与 checkpoint 恢复的相关测试通过；客户端与活动契约一致。
