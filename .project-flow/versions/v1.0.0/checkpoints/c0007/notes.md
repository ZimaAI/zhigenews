## 本轮范围与授权

用户要求去掉已读/未读和整理记录，Agent过程对用户隐藏；新闻详情用弹窗；进度条和预计剩余时间；恢复上一版欢迎页；自动匿名账号、服务器下发Cookie，匿名拥有所有用户端权限；管理员监测异常攻击。用户已确认欢迎页只用于自动进入/加载/失败重试，无邮箱密码注册。仍ITERATE、无基线，不推进阶段。Git main/e7251f3，所有前轮未提交修改保留，本轮也未提交。

## 实现

- 用户设计3.2、管理设计2.2。新闻标题和阅读按钮打开单条Modal，移除read/markRead/未读筛选，用户Run页面删除，旧链接回今日；整期页没有运行记录或技术快照。
- GenerationProgress公开对象提供percent/remainingSeconds/status，不含事件、模型、工具。固定12秒模拟任务由dev服务保存时间；刷新恢复进度/结果，取消与失败保留旧内容，网络不通不误报任务失败。
- Auth恢复r2双栏、Feather与品牌欢迎视觉，自动进入，无凭据表单。用户身份与浏览器偏好缓存按匿名ID隔离；头像进入设置，订阅仍话题/背景/关键词，时间单字段保留；去掉用户退出操作。
- shared/demo-server.ts为Vite开发专用服务，5173签发HttpOnly/SameSite=Lax Cookie（HTTPS时Secure）、7天服务器会话，令牌只存哈希。ignored .demo/anonymous.json保存本地演示账户/计数/策略，Cookie失效新建身份，封禁拒绝不换号。
- 5174代理/__demo到5173，管理模拟Cookie独立，预填admin@example.com/demo-admin只为公开演示凭据。匿名不能访问管理接口；写请求检查Origin和专用header。防护含账号+IP请求/生成限制、同IP建号限制、并发与重复请求合并；429带Retry-After。
- 管理Users页面真实读取开发服务中的匿名账号，提供状态/风险/搜索筛选、详情、封禁/解除、策略和模拟异常审计；其他管理员功能仍原有mock。
- 契约、样例、领域、验收、追踪同步r5：50 schemas、52操作、22样例、24REQ、36AC。用户Brief移除runId/preferenceSnapshot，内部AdminBrief保留；管理员运行接口保留。生产安全方案有OWASP/RFC依据。
