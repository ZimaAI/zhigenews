# 双端原型与候选交互（ITERATE r1 草稿）

原型已落地于 `../prototype/`，用户端和管理员端为两个独立 Vue 3 项目；下表为当前路由与可调整的候选行为。视觉规范唯一来源为根目录 `design.md`。本稿记录产品行为，不作为浏览器检查或正式验收结果。

## 用户端独立项目

| 已落地路由 | 用户能做什么 | 关键状态/待验证目标 |
| --- | --- | --- |
| `/login`、`/register` | 登录或创建账户 | 校验失败、身份失效、提交中 |
| `/onboarding` | 填关注方向、主题、关键词及可选推送 | 保留草稿、跳过外部渠道、保存失败 |
| `/today` | 读今日简报、按主题看内容、手动生成 | 未配置、暂无简报、生成中保留旧内容、无匹配、部分完成、失败 |
| `/briefs/:id` | 完整阅读、看推荐理由/来源/偏好快照 | 引用缺失提示、内容版本、生成与投递分开 |
| `/briefs` | 日期/主题/状态筛选历史 | 无历史、无筛选结果、分页、返回恢复筛选 |
| `/preferences` | 保存主题、包含/排除词、匹配模式、来源偏好和阅读参数；查看/清理长期记忆 | 校验、未保存离开、保存后下次生效；记忆来源、无记忆、清理失败保留数据 |
| `/delivery` | 设置站内/邮件、时间/时区、暂停、测试、重试 | 未验证邮箱、目的地脱敏、发送失败、未知状态、明确下一次日期 |
| `/runs/:id` | 查看本人简化时间线、取消 | 断线待确认、补齐事件、正在取消与已取消分开 |
| `/settings` | 前往兴趣订阅、推送设置与演示账户 | 移动导航入口、退出后返回登录 |

`/` 跳转 `/today`，未知路由回今日。默认演示账户已登录，登录/注册页可单独进入；这不是服务端身份认证。新闻流宽不超过 900px，详情正文不超过 760px；1440px 使用侧栏+单列，移动底部提供今日、历史、设置和更多入口。

## 管理员端独立项目

| 已落地路由 | 操作 | 关键状态/待验证目标 |
| --- | --- | --- |
| `/login` | 模拟管理员登录 | 普通用户禁止进入的交互提示，真实服务端校验待实现 |
| `/overview` | 看运行、采集、投递的示例异常 | 无运行样本不制造百分比、部分组件不可用 |
| `/sources`、`/sources/:id` | 管理 NewsNow/RSS、启停、轮询、验证、手动采集 | 不同源间隔、待验证/退避、最近成功与下次运行 |
| `/models` | 提供商、模型 ID、base URL、key 引用、角色、连接测试 | key 不回显、失败保留非秘密输入、无可用模型 |
| `/agent-configs` | 参数/提示词/工具/子 Agent 配置草稿与发布 | 校验、版本差异、新运行生效 |
| `/runs`、`/runs/:id` | 按状态/模型/时间过滤，查看父子运行与模拟事件 | 工具动作/错误、摘要压缩、文件版本冲突、取消；真正消息修复与预算行为由后端验收 |
| `/evaluations`、`/evaluations/:id` | 管理固定样例，运行实验，比较配置与评分 | 排队/运行/失败、人工与模型评分来源、未配置评估模型 |
| `/users`、`/deliveries` | 用户状态和投递故障管理 | 权限拒绝、重试原简报、提交成功与送达未知分开 |

`/` 跳转 `/overview`，未知路由回概览。后台使用同样设计变量和基础组件，表格/时间线比用户端更详细；敏感信息脱敏，长日志只在局部滚动。模型角色包括主模型、摘要模型、评估模型和子模型。

## 本轮候选行为

- 有效订阅为至少一个主题**或**至少一个包含关键词，允许仅关键词订阅。required 模式仍需至少一个包含关键词；排除规则优先，来源至少选择一种。
- 偏好保存增加版本，仅新生成使用；原简报保留偏好快照。条数 1–30，窗口上限 168 小时；语言和深度可保存，本轮固定示例正文不经真实模型改写。
- 新生成创建新 run 与内容版本；同一活动生成复用运行。取消先显示取消中，随后确认取消；已发布内容保留。
- 重试发送沿用同一 briefId，不重新生成内容；需满足邮件启用和地址模拟验证条件。submitted 仅表示已提交，没有送达回执。
- 来源轮询以秒保存；NewsNow 不短于上游配置周期，RSS 单独配置。模型保存清除连接验证状态，原型只存 key 遮罩；发布 Agent 草稿影响后续运行。
- 评估采用固定样例，待评分用空值；模型评分和引用规则检查分开展示。真实 Agent Loop、工具沙箱、消息修复、摘要压缩与评分执行仍属后端实施范围。

## 原型交互与数据约束

原型固定时钟为 `2026-09-18T08:12:00+08:00`，使用集中内存 adapter，页顶提供场景和重置入口并持续标明模拟。新闻标题/正文/运行/发送/评分均为 synthetic；来源外链为参考资料，不能当作当天真实新闻发布证据。

正常、加载、空内容、请求失败、部分完成、无权限场景可切换；切换和重置清除当前模拟异步任务并恢复固定 seed。两端分别运行于 5173/5174，localStorage 按 origin 独立；管理员修改不会实时同步到另一端。它们在正式实现时才共享 HTTP 后端。

第一条可点击链路：模拟注册/首次配置 → 保存主题或关键词 → 生成 → 查看简报 → 打开参考来源 → 查看邮件失败 → 重试同一期。

管理链路：新增模型配置 → 模拟连接测试 → 发布 Agent 参数 → 进入示例运行 → 查看工具/摘要/子任务 → 比较两次固定样例实验。

每个可用操作修改本地演示状态，不调用真实服务。`npm run check:contract` 校验契约固定样例与实际 seed；详情见 `../prototype/README.md`。真实 HTTP 的错误、权限、幂等、SSE 和持久化语义见 `../contracts/README.md`，不以模拟交互代替后端证明。

原型检查目标包括桌面与 320/375/768px 重排、200% 文字缩放、长标题/长关键词、表单保留输入、键盘导航和弹窗焦点。逐项结果与证据由阶段报告记录；此处不统一宣告通过。下一轮仍在 ITERATE 调整原型与方案，尚未定稿或冻结。
