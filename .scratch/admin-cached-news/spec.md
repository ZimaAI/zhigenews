# 管理员浏览缓存新闻

管理员在正式管理控制台浏览各新闻来源已采集、仍在当前新闻索引中的新闻。沿用来源新闻索引的最近 24 小时发布时间范围，不触发采集，不改变缓存保留策略。

## 验收范围

- 增加缓存新闻导航，提供全部来源与按来源筛选、标题关键词搜索、服务端分页。
- 新闻来源列表与详情均可进入对应来源的缓存新闻。
- 详情显示缓存文本、发布时间、采集时间、来源、原文链接与证据/快照标识；列表返回保留筛选与页码。
- 仅管理员可读取 API；正常、加载、空、请求失败、刷新失败保留数据、缓存已移除状态明确。
- 复用管理员视觉、共享基础组件；兼容移动端和键盘。
- 验证 API 权限/筛选/分页/详情、请求竞争、前端构建与浏览交互，完成后提交并推送。

当前产品版本 v1.0.0，阶段 FRONTEND_VERIFY；本任务不更改版本流程状态。工作开始时已有未跟踪 prototype/，不属于本次修改。
