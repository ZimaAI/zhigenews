## 启用说明

此变更包含数据库迁移 `0002_source_deletion_jobs.py`。现有环境启用前，需在对应后端环境运行 `alembic -c backend/alembic.ini upgrade head`（命令从仓库根目录运行），并更新/重启 Gateway、Celery worker 和 beat；管理员前端须与新契约一同更新。本次没有迁移实际业务库或重启现有业务服务。

worker 与 Gateway 继续使用现有共享 DATA_DIR 和来源文件锁。beat 负责投递及重启后的重新投递；来源删除任务没有依赖浏览器连接。完成结果来自单项事务提交后的持久记录。

本次验证没有测量实际业务数据的删除加速比例，也没有执行真实上游新闻采集。
