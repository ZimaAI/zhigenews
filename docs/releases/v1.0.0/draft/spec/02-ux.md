# 双端原型与候选交互（ITERATE r3 草稿）

原型位于 `../prototype/`，用户端与管理员端是两个独立 Vue 3 项目。用户端遵循 [design-user.md](../../../../../design-user.md)，管理员端遵循 [design.md](../../../../../design.md)。本稿记录候选行为，不是浏览器或正式验收报告。

r3 保留用户端浅灰外背景、白色画布、绿色强调与横向导航，进一步精简文字。主导航仅今日简报和简报历史，头像直接进入个人设置。订阅表单只有话题、背景、关键词；推送表单只有每日时间。仅支持站内推送，首次进入先引导配置偏好。管理员风格继续沿用深青绿侧栏控制台。

## 用户端独立项目

| 路由 | 用户能做什么 | 关键状态 |
| --- | --- | --- |
| `/login`、`/register` | 登录或创建账户 | 校验、提交中、失败保留输入 |
| `/onboarding` | 一页填写话题、背景、关键词后开始阅读 | 未保存/保存失败留在引导；成功持久化完成标记 |
| `/today` | 读今日简报、主题筛选、手动生成 | 暂无简报、生成中保留旧内容、无匹配、部分完成、失败 |
| `/briefs/:id` | 阅读摘要、理由与可追溯来源 | 内容版本、缺失引用、返回入口 |
| `/briefs` | 搜索和筛选历史简报 | 无历史、无匹配、分页 |
| `/settings` | 头像进入个人设置，默认到订阅偏好 | 兴趣和推送时间两个子页，退出账户 |
| `/settings/preferences` | 只编辑话题、背景、关键词 | 至少一个话题或关键词、显式保存、未保存离开、失败保留草稿 |
| `/settings/schedule` | 只编辑每日自动推送时间 | HH:mm 校验、保存中、失败保留输入 |
| `/runs/:id` | 查看本人简化运行状态和时间线、取消 | 连接待确认、正在取消与已取消分开 |

旧 `/preferences` 重定向 `/settings/preferences`，旧 `/delivery` 重定向 `/settings/schedule`。`/` 和未知路由默认到今日。未登录访问受保护页面进入登录；已登录但 `onboardingCompleted=false` 的用户先进入引导。首次有效偏好保存后再进入今日；刷新或重新登录不重复引导，注册重新清空该账户偏好并进入引导。

话题使用紧凑多选控件，无大面积封面、分类或候选搜索。背景可空、最多 500 字；关键词最多 20 个、每个最多 40 字，支持添加/删除，仅通过保存更改持久化偏好。字段说明只在必要时出现。普通阅读页面保留实际新闻内容和来源，删除重复教学、营销口号、参数说明与邮件状态。

桌面最大 1120px 白色画布，新闻流不超过 900px，详情正文不超过 760px。设置表单收窄。手机表单单列，话题自然换行，不以裁切隐藏操作。没有桌面侧栏或重复固定手机导航。

## 管理员端独立项目

| 已落地路由 | 操作 | 关键状态/待验证目标 |
| --- | --- | --- |
| `/login` | 模拟管理员登录 | 普通用户禁止进入的交互提示，真实服务端校验待实现 |
| `/overview` | 看运行、采集、投递的示例异常 | 无运行样本不制造百分比、部分组件不可用 |
| `/sources`、`/sources/:id` | 管理 NewsNow/RSS、启停、轮询、验证、手动采集 | 不同源间隔、待验证/退避、最近成功与下次运行 |
| `/models` | 提供商、模型 ID、base URL、key 引用、角色、连接测试 | key 不回显、失败保留非秘密输入、无可用模型 |
| `/agent-configs` | 参数/提示词/工具/子 Agent 配置草稿与发布 | 校验、版本差异、新运行生效 |
| `/runs`、`/runs/:id` | 按状态/模型/时间过滤，查看父子运行与模拟事件 | 工具动作/错误、摘要压缩、文件版本冲突、取消；真正消息修复与预算行为由后端验收 |
| `/evaluations`、`/evaluations/:id` | 管理固定样例，运行实验，比较配置与评分 | 排队/运行/失败、人工与模型评分来源、未配置评估模型 |
| `/users`、`/deliveries` | 用户状态和投递故障管理 | 权限拒绝、重试原简报、站内发布成功与状态未知分开 |

`/` 跳转 `/overview`，未知路由回概览。后台使用 `design.md` 的原深青绿默认变量、侧栏与基础组件，表格/时间线比用户端更详细；敏感信息脱敏，长日志只在局部滚动。模型角色包括主模型、摘要模型、评估模型和子模型。用户端主题独立加载，不覆盖后台样式。

## 本轮候选行为

- 用户偏好仅 `version/role/topics/keywords`；version 由系统管理，表单不编辑。未配置读取允许 version 0 和空数组；保存至少一个话题或关键词，背景可空。
- 保存偏好原子递增版本并完成首次配置，仅新运行使用新偏好。历史简报保留原快照。模拟筛选最近 24 小时内命中任一所选话题或任一关键词的内容，最多 10 条，无匹配不凑数；背景仅保存供正式 Agent 语义使用。全部来源和中文标准摘要为内部默认值，不受移除的旧用户字段影响。
- 每日站内自动推送默认 08:00、系统时区 Asia/Shanghai；用户只改时间。没有邮件地址、验证、测试发送、渠道、时区或暂停开关。账号邮箱仅作登录身份。
- 新生成创建新 run 与内容版本；同一活动生成复用运行。取消先显示取消中再确认，已有内容保留。站内发布重试由管理员处理，沿用同一 briefId；submitted 表示已发布，不表示用户已读。
- 来源周期以秒保存，NewsNow 不短于上游周期，RSS 独立配置。模型保存重置验证状态，原型只存 key 遮罩；Agent 发布影响后续运行。
- 评估使用固定样例，待评分为 null；真实 Agent Loop、沙箱、消息修复、摘要与持久记忆仍属后端范围，用户偏好页不再暴露记忆控件。

## 原型交互与数据约束

原型固定时钟 `2026-09-18T08:12:00+08:00`，使用集中内存 adapter。页顶保留简短模拟标记和场景/重置入口。新闻、运行、发布与评分均为 synthetic，来源外链是参考资料，不作为当天真实报道的证明。

正常、加载、空内容、请求失败、部分完成、无权限场景可切换；切换和重置均清除当前模拟异步任务；场景切换保留已保存偏好和首次完成标记，“重置全部示例”恢复 seed 并清空完成标记。两端 5173/5174 的 localStorage 按 origin 独立，正式阶段才对接同一个 HTTP 后端。

用户链路：首次进入 → 设置话题/背景/关键词 → 阅读或生成简报 → 查看来源 → 头像进入设置 → 修改偏好或每日时间。管理链路：配置并测试模型 → 发布 Agent 参数 → 查看运行事件与子任务 → 比较固定样例实验 → 处理站内发布故障。

`npm run check:contract` 校验固定样例和实际 seed，详见 `../prototype/README.md`。浏览器需覆盖首次引导持久化、头像导航、字段删减、保存与失败、未保存离开、生成阅读、手机换行和键盘操作；实际结果记入阶段证据。仍停留 ITERATE，尚未定稿或冻结。
